Pengaturan tarif

Tarif reguler dihitung bertingkat per kelompok kubikasi; biaya beban Rp5.000 ditambahkan setiap bulan. Fasilitas umum memakai tarif tetap Rp2.500/m³ + biaya beban.

Tarif bertingkat: 0–5 m³ Rp3.000; 6–10 m³ Rp3.500; 11–20 m³ Rp4.000; di atas 20 m³ Rp7.500. Total = jumlah setiap kelompok + biaya beban Rp5.000. Fasilitas umum: kubikasi × Rp2.500 + biaya beban.

Sinkronisasi / backup Google Sheets

Hubungkan aplikasi ke Google Sheets melalui Google Apps Script. URL disimpan di browser ini.

Petunjuk pemasangan Google Sheets

  1. Buat Google Spreadsheet baru.
  2. Pilih Ekstensi → Apps Script.
  3. Ganti kode di editor dengan kode berikut, lalu simpan.
  4. Pilih Deploy → New deployment → Web app. Execute as: Me, Who has access: Anyone. Deploy dan izinkan akses.
  5. Salin URL Web App berakhiran /exec ke kolom di atas.

Catatan: backup akan menulis ulang tiga sheet Pelanggan, Tagihan, dan Tarif pada spreadsheet aktif. Gunakan spreadsheet khusus untuk aplikasi ini. Pengiriman lintas domain dari browser dapat tidak menampilkan konfirmasi respons; periksa Google Sheets setelah mengirim.
